# ReadyOn — Трек-дни на спортивных автомобилях

> ⚡ **Статус:** Фронтенд завершён. Проект готов к переносу на C# / ASP.NET MVC.

Лендинг для компании ReadyOn, организующей трек-дни на гоночных трассах Бельгии. Проект выполнен на чистом JavaScript с использованием Vue.js для интерактивных элементов.

## 🚀 Функционал

- **Адаптивная вёрстка** — от мобильных устройств до десктопа
- **Бургер-меню** — плавное открытие/закрытие на мобильных
- **Галерея спорткаров** — 4 автомобиля с собственными наборами изображений
- **Сравнение автомобилей** — интерактивная таблица на Vue.js с анимированными полосками
- **FAQ-аккордеон** — плавное раскрытие ответов
- **Плавный скролл** к секциям по якорным ссылкам
- **Подарочные сертификаты** — секция с описанием и изображением

## 🛠 Технологии

- HTML5
- CSS3 (Flexbox, Grid, CSS Variables)
- JavaScript (Vanilla)
- Vue.js 3 (CDN)
- SVG-спрайты для иконок


## 🔧 Особенности реализации

### Сравнение автомобилей (Vue.js)
- Реактивная таблица с динамическими полосками
- Автоматическое определение победителя по характеристикам
- Поддержка метрик "чем больше, тем лучше" и "чем меньше, тем лучше"

### Галерея спорткаров
- 4 автомобиля: Porsche 911 GT3, BMW M4, Nissan GTR-35, Audi R8
- Клик по карточке меняет всю галерею и характеристики
- Миниатюры меняются местами с главным изображением

### Программа заезда
- Десктопная версия с карточками на всю ширину
- Мобильная версия с вертикальными карточками и изображениями

## 🖥 Готовность к переносу на C# / ASP.NET

Проект полностью подготовлен для интеграции в бэкенд на C#:

- **Чёткая структура** — HTML, CSS и JS разделены по папкам, легко переносятся в `wwwroot`
- **Статические данные** — все данные автомобилей вынесены в JS-объекты, готовы к замене на API-запросы
- **Формы** — секция контактов (`mail__form`) готова к привязке к контроллерам ASP.NET
- **Vue.js через CDN** — не требует Node.js, работает в любом окружении
- **SVG-спрайты** — иконки встроены в HTML, не требуют дополнительных файлов
